# 学院综测成绩审核程序 · v1.0

> 太原科技大学 · 计算机科学与技术学院　综合素质测评成绩处理工具
> 一站式完成 **两表核对 → 挂科/附加分筛查 → 综测总表回填** 三个环节。

一个入口、三个任务，规则固化在引擎里、界面只做调度与展示，**只读源表、写入前自动备份**，
大幅降低人工核对 Excel 的出错率。

- 版本：**v1.0**（文件版本 `1.0.0.0`）
- 作者：**程震宇**
- 运行平台：Windows（单文件 exe / 安装包均自包含，目标机无需安装 Python）

## 功能概览

| # | 任务 | 作用 | 输入 | 产出 |
|---|------|------|------|------|
| ① | **综测两表核对** | 校验「综合素质测评详情表」与「综合素质测评表」两份表是否一致，按 **必须处理 / 需确认 / 提示** 三级列出问题 | 年级文件夹（每班一个子文件夹，内含两份 xlsx） | 核验报告 xlsx（**只读源表，绝不写回**） |
| ② | **挂科 / 附加分筛查** | 识别必修课 → 判定挂科学生（可整行标黄）→ 认定必修课 100 分附加分资格 | 年级文件夹 或 学期根目录（含各班 `班级成绩(xx).xlsx`） | 《挂科与附加分表.xlsx》（7 个 Sheet） |
| ③ | **回填成绩表** | 依据 ② 的产出，把「是否挂科」「附加分」回填到各年级综测总表 | 综测总表目录 + ② 产出的 xlsx | 回填核验报告 md（**并直接写入总表**） |

> **③ 依赖 ②**：③ 的数据源就是 ② 产出的《挂科与附加分表.xlsx》，两个任务请按顺序执行。

## 下载与安装

提供三种使用方式，任选其一：

### 方式一：安装包（推荐）

下载 **`综测核算程序_Setup.exe`**（约 21 MB，Inno Setup 制作），双击按向导安装：

- 默认安装到 `C:\Program Files\综测核算程序`
- 自动创建开始菜单项与卸载程序
- 可选创建桌面快捷方式
- 安装完成可直接启动

> 卸载：开始菜单 → 「卸载 综测核算程序」，或系统「应用和功能」中卸载。

### 方式二：免安装单文件

下载 **`综测核算程序.exe`**（约 20 MB），双击即用，无需安装、无需 Python 环境。

> 单文件 exe 每次运行会解包到 `%TEMP%\_MEIxxxx`，首次启动稍慢，属正常现象。

### 方式三：从源码运行

见 [从源码运行](#从源码运行)。

## 快速开始

1. 打开程序，首页选择产物**输出根目录**（默认落在「下载」文件夹下的 `班级成绩处理结果`）。
2. 选择要执行的任务（① / ② / ③）。
3. 在任务页选择数据目录，点击「开始」。
4. 处理完成后可一键「打开」产物所在目录。

> **运行前请关闭所有正在打开的 Excel**：Windows 下被 Excel 占用的 xlsx 会被锁定，写入会失败。

## 三个任务详解

### ① 综测两表核对

- 逐个学生比对打分项与总分，问题分三级：**必须处理 / 需确认 / 提示**。
- 结果「问题清单」**只显示不通过学生的问题与原因**（另保留文件级/班级级要紧问题、人员缺失）；其余提醒类问题仅写入报告。
- 上限（`CAP`）与扣分项（`DEDUCT_ITEMS`）规则写在 `verify.py`。
- **只读源表，绝不写回**，输出核验报告 xlsx。

### ② 挂科 / 附加分筛查

- **必修课识别**：该课程列有成绩的人数 ≥ 班级实际人数 **90%**（零星列如重修/补修/智慧树公选不算）。
- **挂科判定**：必修列中 `<60` / `不及格` / `缺考·缓考·取消资格` 等。
- **成绩标记**：`60$`=补考、`60*`=重修，剥离标记后按数值判，**60 分算通过**。
- **附加分**：必修列**数字**成绩 `== 100`（五档制的「优」不算；只列资格）。
- **标黄**：挂科学生**整行**（A 到最后一列）填标准黄。
- **「人」与「门次」分开统计**（一人可挂多门）。
- 产出《挂科与附加分表.xlsx》，共 7 个 Sheet：
  `挂科汇总` / `挂科明细` / `附加分汇总` / `附加分明细` / `班级统计` / `课程认定明细` / `规则说明`。

### ③ 回填成绩表

- **是否挂科** ← 「挂科汇总」学号集合：命中填 `是`，否则填 `否`。
- **附加分** ← 「附加分汇总」的 `100分门数`：几门加几分，**没有必须填 `0`**（E 列参与 `F=D+E` 公式，不能留空）。
- **学号归一化**：统一 12 位文本，比对前 `strip()` 并去掉 Excel 文本前缀撇号（`'202420010301`）。
- **身份双重确认**：学号 + 班级；学号结构 = 年级 4 位 + 专业码 4 位 + 班号 2 位 + 序号 2 位。
- **年级对齐**：先用目录内学生学号的年级众数锁定年级，只取源表同年级名单。
- **写入前自动备份**到 `<目录>/_备份_修改前_时间戳/`。

## 技术栈

- **语言**：Python 3.11
- **界面**：tkinter（自绘圆角控件 + Pillow 渲染）
- **表格读写**：openpyxl 3.1.5（保留公式）
- **打包**：PyInstaller（单文件、无控制台窗口）
- **安装包**：Inno Setup
- **数字签名**：Windows signtool（支持自签名 / 正规 CA 证书）

## 从源码运行

### 环境要求

| 项 | 要求 |
|----|------|
| Python | 3.9+（打包实测 3.11.9，需自带 tkinter 的标准安装版） |
| openpyxl | 3.1.5 |
| pillow | 最新 |

```bash
pip install openpyxl==3.1.5 pillow
python main.py
```

> Windows 上请用 `python.exe`（而非 `pythonw.exe`）启动，否则看不到日志。
> 若提示 `No module named tkinter`，说明装的是 embeddable 精简版，请换标准安装版。

### 命令行自检

```bash
综测核算程序.exe --selftest
```

退出码 `0` 表示界面与引擎加载正常；失败时会在同目录生成 `selftest_error.txt`。

## 重新打包与签名

> 需要 Python 3.11 + `pyinstaller openpyxl==3.1.5 pillow`（建议虚拟环境）。

```bash
# 1) 建虚拟环境并安装依赖
python -m venv buildenv
buildenv\Scripts\pip install pyinstaller "openpyxl==3.1.5" pillow

# 2) 一键打包 + 自签名
python build.py

# 用正规 CA 证书签名
SIGN_PFX=my.pfx SIGN_PWD=123456 python build.py
```

产物：`dist\综测核算程序.exe`（已签名）。

### 生成安装包

需先安装 [Inno Setup](https://jrsoftware.org/isdl.php)，然后：

```bash
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss
```

产物：项目根 `综测核算程序_Setup.exe`。

### 版本与签名说明

- **版本资源**：`version_info.txt`（作者 = **程震宇**，文件/产品版本 = `1.0.0.0`），由 spec 的 `version=` 嵌入 exe，右键属性 → 详细信息可见。
- **自签名**（默认）：不设 `SIGN_PFX` 时，`build.py` 会生成 `CN=程震宇` 的自签名证书签名。**签名真实有效，但 Windows 会提示「发布者未验证」**（未经 CA 信任，属正常现象）。
- **正规证书**：设置 `SIGN_PFX` / `SIGN_PWD`（可选 `SIGN_TIMESTAMP`），Windows 不会拦截。

## 注意事项

1. **运行前关闭所有打开的 Excel**，否则写回会因文件被占用失败。
2. **附加分列必须填 `0`** 而不是留空（总表 `F = D + E` 公式依赖该值）。
3. ③ 会**直接写入**综测总表，但写入前一定会先备份到 `_备份_修改前_时间戳/`。
4. 跨年级跟班生（学号年级 ≠ 名单班级年级）属正常情况，程序不会误报。
5. 若 Windows 提示「发布者未验证」，是**自签名证书**的正常提示，可点击「仍要运行」。
6. 产物默认输出到「下载」文件夹下的 `班级成绩处理结果`，可在首页或任务页修改。
